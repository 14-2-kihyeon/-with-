# 챗봇 응답 구조 개선: 요약-해석-마무리 형식

## 문제점
사용자가 "삼전 어때?" 질문에 대한 챗봇 응답이 중간에 끊긴 것처럼 보였습니다:
- 요약 부분은 있었으나 해석이 불완전
- 마무리 문장 없이 갑자기 종료
- 대화 흐름이 자연스럽지 않음

## 해결 방안


### 2. 마무리 문장 보존 로직

응답이 길어서 줄 수 제한에 걸리더라도 마무리 문장을 보존하도록 개선했습니다.

**마무리 문장 감지 패턴** - [services.py:1135-1144](c:\Users\kint_\Desktop\pjt\-with-\Backend\chatbot\services.py#L1135-L1144)
```python
closing_patterns = [
    r'궁금한.*말씀',
    r'도움.*되[^가-힣]*좋겠',
    r'문의.*주[시세]',
    r'투자.*결정',
    r'추가.*질문',
    r'언제든.*말씀',
    r'더.*필요.*사항',
]
```

**마무리 문장 보존 알고리즘** - [services.py:1146-1190](c:\Users\kint_\Desktop\pjt\-with-\Backend\chatbot\services.py#L1146-L1190)
1. 줄 수가 20줄을 초과하는 경우에만 제한 적용 (이전: 15줄)
2. 일반 컨텐츠는 최대 15개까지 허용 (이전: 12개)
3. 컨텐츠 제한을 초과하더라도 마무리 문장은 반드시 포함
4. 마무리 문장이 없으면 자동으로 기본 마무리 추가

```python
if content_count < max_content:
    result_lines.append(line)
    content_count += 1
    if is_closing:
        found_closing = True
elif is_closing and not found_closing:
    # 제한을 넘었지만 마무리 문장이면 포함
    result_lines.append(line)
    found_closing = True
    break

# 마무리 문장이 없으면 마지막에 기본 마무리 추가
if not found_closing and result_lines:
    result_lines.append('')
    result_lines.append('더 궁금한 점이 있으시면 언제든 말씀해주세요.')
```

## 테스트 결과

**질문**: "삼전 어때?"

**응답 구조**:
```
요약:
- 삼성전자(005930) 최근 시세: 110,500원 (전일 +4,200원, +3.95%)
- 단기 수익률: 5일 +0.05%, 20일 +0.14%
- 단기 변동성: 0.02% (안정적)
- 최근 뉴스: 텍스트마이닝, 반도체 장비 호재 등

해석 (사용자 프로필 고려):
- 투자자는 공격형(테토투기형) 성향(점수 100), 30세로 높은 위험도를 감내할 수 있습니다.
- 삼성전자는 대형주로서 안정적이며 단기 변동성이 낮아 포트폴리오에 적합합니다.
- 다만 투자 목표가 '주택구매'이고 기간이 36개월(단기~중기)인 점을 고려하면,
  주식은 단기 가격 변동성으로 인해 원금 손실 가능성이 있으므로
  투자 비중 조절이 필요합니다. 목표 달성을 위해 안정적 자금 확보도 필요합니다.

더 궁금한 점이 있으시면 말씀해주세요.
```

✅ **요약**: 시세, 수익률, 변동성, 뉴스 포함
✅ **해석**: 사용자 프로필(공격형, 30세, 주택구매, 36개월) 고려한 적합성 평가
✅ **마무리**: 자연스러운 대화 마무리 문장

## 개선 효과

1. **구조화된 응답**: 요약-해석-마무리의 3단계 구조로 일관성 있는 답변
2. **완전한 대화**: 더 이상 중간에 끊기지 않고 자연스럽게 마무리
3. **사용자 프로필 활용**: 단순 정보 전달이 아닌 개인화된 해석 제공
4. **대화 흐름 유지**: 마무리 문장으로 추가 질문을 유도하여 대화 지속
