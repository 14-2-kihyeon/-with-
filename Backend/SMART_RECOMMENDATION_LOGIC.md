# 복합 조건 기반 스마트 추천 로직

## 개요

사용자의 **저축액**, **투자기간**, **투자목표**를 종합적으로 고려하여 예금/적금 추천 비율을 동적으로 조정하는 시스템

---

## 문제 인식

**이전 문제점**:
- 무조건 금리순 정렬 → 적금 15개만 표시 (적금 금리가 예금보다 2배 높음)
- 사용자 상황 무시 (목돈 있어도 적금만 추천, 단기 목표인데 장기 상품 추천 등)

**개선 방향**:
- 사용자 프로필 분석하여 **예금/적금 비율을 스마트하게 조정**
- 예: 목돈 많으면 예금 비중 높이기, 장기 투자면 적금 비중 높이기

---

## 점수 기반 비율 계산 시스템

### 함수: `_calculate_product_ratio()`

```python
def _calculate_product_ratio(savings_amount, investment_period, investment_goal):
    """
    복합 조건 기반 예금/적금 추천 비율 계산

    총 100점 만점으로 점수를 계산하고 비율로 변환
    - 저축액: 0~40점
    - 투자기간: 0~40점
    - 투자목표: 0~20점
    """
```

---

## 1. 저축액 기반 점수 (0~40점)

### 로직

| 저축액 범위 | 예금 점수 | 적금 점수 | 해석 |
|------------|----------|----------|------|
| **5,000만원 이상** | **40점** | 10점 | 목돈 운용 → 예금 강력 선호 |
| 3,000~5,000만원 | 30점 | 20점 | 목돈 있음 → 예금 선호 |
| 1,000~3,000만원 | 20점 | 30점 | 보통 → 균형 |
| **1,000만원 미만** | 10점 | **40점** | 적은 금액 → 적금으로 모으기 |

### 이유

- **목돈이 있으면** → 예금에 넣어서 안정적으로 이자 받기
- **적은 금액이면** → 적금으로 꾸준히 모으기

---

## 2. 투자 기간 기반 점수 (0~40점)

### 로직

| 투자 기간 | 예금 점수 | 적금 점수 | 해석 |
|----------|----------|----------|------|
| **6개월 이하** | **40점** | 10점 | 단기 → 예금 (즉시 인출 가능) |
| 6~12개월 | 30점 | 20점 | 예금 선호 |
| 12~24개월 | 20점 | 30점 | 균형 |
| **24개월 이상** | 10점 | **40점** | 장기 → 적금 (꾸준히 모으기) |

### 이유

- **단기 투자** → 예금 (중도 해지 시 불이익 적음)
- **장기 투자** → 적금 (매달 납입하며 복리 효과)

---

## 3. 투자 목표 기반 점수 (0~20점)

### 로직

| 투자 목표 키워드 | 예금 점수 | 적금 점수 | 해석 |
|-----------------|----------|----------|------|
| **단기**, 비상금, 생활비 | **20점** | 5점 | 즉시 사용 가능해야 함 |
| **장기**, 노후, 은퇴 | 5점 | **20점** | 오래 모으기 |
| 주택, 결혼, 자녀, 교육 | 10점 | 15점 | 중대 목표 (균형) |
| 기타 | 10점 | 10점 | 기본값 |

### 이유

- **비상금** → 예금 (언제든 찾을 수 있어야 함)
- **노후 준비** → 적금 (장기적으로 꾸준히 모으기)
- **주택/결혼** → 균형 (목돈도 필요하지만 추가로 모으기도 필요)

---

## 최종 비율 계산

### 공식

```python
총 예금 점수 = 저축액 점수 + 투자기간 점수 + 투자목표 점수
총 적금 점수 = 저축액 점수 + 투자기간 점수 + 투자목표 점수

예금 비율 = 총 예금 점수 / (총 예금 점수 + 총 적금 점수)
적금 비율 = 총 적금 점수 / (총 예금 점수 + 총 적금 점수)

예금 개수 = max(2, min(13, int(15 × 예금 비율)))
적금 개수 = 15 - 예금 개수
```

### 제약 조건

- **최소 보장**: 예금/적금 각각 최소 **2개** 보장
- **최대 제한**: 한쪽이 **13개** 초과 불가
- **총합**: 항상 **15개**

## 실제 예시

### 예시 1: 주택 구매, 36개월, 5,000만원

| 조건 | 예금 점수 | 적금 점수 |
|------|----------|----------|
| 저축액 5,000만원 | **40** | 10 |
| 투자기간 36개월 | 10 | **40** |
| 투자목표 '주택구매' | 10 | 15 |
| **합계** | **60** | **65** |

**계산**:
- 예금 비율: 60 / (60+65) = 48%
- 적금 비율: 65 / (60+65) = 52%

**결과**:
- **예금 7개** (48% ≈ 7.2개)
- **적금 8개** (52% ≈ 7.8개)

### 예시 2: 비상금 마련, 6개월, 500만원

| 조건 | 예금 점수 | 적금 점수 |
|------|----------|----------|
| 저축액 500만원 | 10 | **40** |
| 투자기간 6개월 | **40** | 10 |
| 투자목표 '비상금' | **20** | 5 |
| **합계** | **70** | **55** |

**결과**:
- **예금 8개** (56%)
- **적금 7개** (44%)

**이유**:
- 저축액은 적지만 (적금 선호)
- 투자기간 짧고 (예금 강력 선호)
- 비상금 목표 (예금 강력 선호)
- → 예금 비중이 약간 높음

## 장점

1. **개인화된 추천**: 사용자 상황에 딱 맞는 비율
2. **균형 잡힌 포트폴리오**: 예금/적금 모두 볼 수 있음
3. **투명한 추천 이유**: 왜 이 비율인지 설명 제공
4. **유연성**: 3가지 조건의 가중치 조정 가능

---

## 개선 가능 사항

1. **가중치 조정**: 현재 저축액(40점), 투자기간(40점), 투자목표(20점) → 사용자 피드백 기반 최적화
2. **더 세분화된 구간**: 예) 10,000만원 이상은 예금 50점 등
3. **위험 성향 추가**: 공격적 투자자는 적금 비중 높이기
4. **머신러닝**: 사용자 클릭/선택 패턴 학습하여 개인화
