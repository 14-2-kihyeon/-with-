# 챗봇 아바타 이미지

이 폴더에 다음 3개의 이미지 파일을 추가해주세요:

## 필요한 이미지 파일

1. **timid-avatar.png** - 안정형 투자자를 위한 챗봇 아바타
   - 파란색 계열, 안정적이고 신뢰감 있는 이미지
   - 권장 크기: 200x200px 이상

2. **normal-avatar.png** - 중립형 투자자를 위한 챗봇 아바타
   - 파란색/녹색 계열, 균형감 있는 이미지
   - 권장 크기: 200x200px 이상

3. **speculative-avatar.png** - 공격형 투자자를 위한 챗봇 아바타
   - 녹색/주황색 계열, 역동적이고 적극적인 이미지
   - 권장 크기: 200x200px 이상

## 임시 이미지 사용

이미지가 없는 경우, 챗봇은 기본 그라데이션 아이콘을 표시합니다.
원하는 이미지를 위 파일명으로 저장하시면 자동으로 적용됩니다.

## 이미지 제작 가이드

- 투명 배경 PNG 권장
- 심플하고 친근한 디자인
- 투자 성향에 맞는 색상 사용
- 챗봇의 개성을 표현할 수 있는 캐릭터나 아이콘
